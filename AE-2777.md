# AE-2777 Muuttuva energiamuotokerroin (kaukolämpö)

## Tiketti
Laatijan tulee pystyä muuttamaan ET2027 merkittyä kaukolämmön energiamuotokerrointa,
jos energiatodistuksen laatimisvaihe on “olemassa oleva rakennus”. Muissa
laadintavaiheissa kaukolämmön energiamuotokerroin 0,38. “Olemassa olevissa
rakennuksissa” ehdottaa energiamutokertoimeksi 0,38 ja se on laatijan vaihdettavissa
välillä 0,2 … 0,38 . Kaikki muut energiamuotokertoimet pysyvät vakioina.

# Vaatimukset
- Laatijan tulee pystyä muuttamaan ET2027 merkittyä kaukolämmön energiamuotokerrointa.
- Tämä muutos pätee vain versiolle 2027, kun laadintavaihe on "olemassa oleva rakennus".
- Kaikki muut energiamuotokeroimet pysyvät vakiona.

- Rajat:
  * Min 0.2
  * Max 0,38

## Migraatio

Uusi kenttä:
```sql
alter table energiatodistus
    add column t$kaytettavat_energiamuodot_kertoimet$kaukolampo numeric;

alter table audit.energiatodistus
    add column t$kaytettavat_energiamuodot_kertoimet$kaukolampo numeric;

call audit.create_audit_procedure('energiatodistus'::name);
```

Uudesta kentästä seuraa suoraan sijainti clojure ja json-datarakenteissa.

Lisäksi uudet rajat 0,2 .. 0,38 tulee päivittää repeatable migraatioon. Tästä seuraa frontendin lomakkeen validoinnin
toiminta vastaavasti kuin muillekin kentille.

Tämä kenttä ei tule sarakkeeksi csv:hen, vaan sillä korvataan nykyinen "Tulokset / Kaytettavat-energiamuodot / Kaukolampo-kerroin"
arvo kun se on asetettuna.

## Backend muutokset
solita.etp.service.e-luokka/energiamuotokerroin on paikka, jossa nykyiset vakiokertoimet on asetettu. Tämän täytyy
muuttua siten, että saadaankin 2027 tapauksessa yksittäiselle energiatodistukselle asetettu kerroin.

## Frontend muutokset
Backendiä vastaava kovakoodaus energiamuotokertoimelle tulee muuttaa siten, että se katsotaan 2027 tapauksessa
energiatodistuksesta.

2027-energiatodistuslomakkeella arvon syöttöpaikka tulee e-luvun-erittely.svelte tiedostoon. Tämän arvon ollessa null
näkyy kentässä default arvo (0,38) ja muussa tapauksessa siihen syötetty arvo.
