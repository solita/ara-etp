# AE-2665 Consume openhtmltopdf library from new coordinates

At time of starting, ETP uses com.openhtmltopdf/openhtmltopdf-pdfbox from
Maven to generate PDF files from HTML input

We want to switch to consuming it from io.github.openhtmltopdf/openhtmltopdf-pdfbox
because that is where recent development delivers to

## Definition of done

- [deps.edn](etp-core/etp-backend/deps.edn) consumes io.github.openhtmltopdf/openhtmltopdf-pdfbox 1.1.105
  - an older version is acceptable, but only with good rationale
- clojure -M:dev:test runs to completion, successfully


## How to run the relevant parts of the test suite

The full backend test suite should finally pass, but initially it can suffice
and be more efficient to just run the tests that exercise PDF generation:

```bash
cd etp-core/etp-backend/
clojure -M:dev:test \
    solita.etp.service.pdf-visual-regression-test/energiatodistus-2026-with-perusparannuspassi-visual-regression-test \
    solita.etp.service.pdf-heading-hierarchy-test/energiatodistus-2026-with-perusparannuspassi-heading-hierarchy-test
```
